Multiple Vulnerabilities in Google Chrome Could Allow for Arbitrary Code Execution

Source: Center for Internet Security - Multi-State Information Sharing and Analysis Center

Catégorie: security

Multiple vulnerabilities have been discovered in Google Chrome, the most severe of which could allow for arbitrary code execution. Successful exploitation of the most severe of these vulnerabilities could allow for arbitrary code execution in the context of the logged on user. Depending on the privileges associated with the user an attacker could then install programs; view, change, or delete data; or create new accounts with full user rights.
